# 微信头像上传问题解决方案

## 问题描述
在微信小程序真机测试中，微信头像下载失败，错误信息：
```
downloadFile:fail network argv error
errno: 600005
```

## 问题原因分析

### 1. 网络权限问题
微信小程序在真机上对网络请求有严格的限制：
- 必须使用 HTTPS 协议
- 需要在微信公众平台配置服务器域名白名单
- 微信头像URL可能需要特殊处理

### 2. 微信头像URL格式问题
微信返回的头像URL可能是HTTP格式，需要转换为HTTPS

## 解决方案

### 1. 代码层面优化 ✅ 已完成

#### 增强错误处理
- 添加了详细的错误日志
- 根据不同错误类型给出具体提示
- 增加了文件验证逻辑

#### URL格式处理
- 自动将HTTP转换为HTTPS
- 添加下载超时设置（10秒）
- 验证下载文件的有效性

#### 修改的文件
- `pages/edit-profile/edit-profile.js`
  - `processWechatAvatar()` 函数
  - `saveAvatar()` 函数
  - 新增 `handleAvatarError()` 函数

### 2. 微信小程序配置 ⚠️ 需要手动配置

**downloadFile合法域名：**

## 测试步骤

### 1. 开发者工具测试
- 在微信开发者工具中测试头像上传功能
- 查看控制台日志，确认URL格式和下载过程

### 2. 真机测试
- 使用体验版进行真机测试
- 观察错误日志，确认问题是否解决

### 3. 网络调试
- 在真机上打开调试模式
- 查看Network面板，确认网络请求状态

## 常见问题排查

### 1. 仍然出现 600005 错误
- 检查微信公众平台的域名配置
- 确认所有相关域名都已添加到白名单
- 重新发布小程序版本

### 2. 头像下载成功但上传失败
- 检查后端服务器是否正常运行
- 确认OSS配置是否正确
- 查看后端日志排查问题

### 3. 开发工具正常但真机异常
- 这是典型的域名白名单问题
- 重点检查微信公众平台的域名配置
- 确保使用HTTPS协议
